# Subastas en línea con pujas y cuenta regresiva

Consulta `AGENTS.md` para las reglas de desarrollo y de agentes.

## Flujo de trabajo obligatorio
1. Lee `docs/progreso.md` para ubicar la feature actual.
2. Lee la especificación aprobada en `docs/specs/`. No programes sin especificación.
3. Al terminar, corre `npm run check` para validar formato, lint, tipos y pruebas.
4. Genera la nota de entrega en `docs/handoffs/` y actualiza `docs/progreso.md`.
